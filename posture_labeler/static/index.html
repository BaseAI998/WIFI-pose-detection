几分钟就能开始标注

  1. 左侧默认每 3 秒抽样；可输入输出帧号 2400 定位已知问题。
  2. 看中间原图和右侧放大图；点击人物框或 P 按钮选择目标。
  3. 先按需要选择腿部遮挡、填写备注，再按 1 / 2 / 3 / 4 标姿态。提交成功才会自动切换。
  4. 原图能确认坐着，即使腿看不见也标坐着。站着弯腰仍属站立。人工无法确定或正在起身时标不确定。
  5. 重复框只给一个框标姿态，其余选忽略。漏检的人本工具暂不能补画框。
  6. 每次修改会保存到本机数据库；刷新或重启可继续。取消「自动进入」可逐个复核。
  7. 「导出训练数据」得到 JSONL，包含原图帧号、框、17 个关键点和人工标签。CSV 便于核查。导出包含所有已标样本，不受左侧筛选限制。
不确定和忽略不会标为可训练的站/坐样本。导出不会自动划分训练集 / 测试集；后续请按不相邻时间段划分，避免相邻帧泄漏。
